# 용돈 친구 🐣

초등학생을 위한 터치형 용돈기입장입니다. 기록을 잘하면 캐릭터가 자라요.

- 저금통 5개(소비·경조사·저금통·은행 갈 돈·기부)와 용돈 계약서에 따른 자동 나누기
- 2주 돌아보기, 목표 저축, 은행 입금과 통장 사진 미션(AI가 잔액을 읽음), 적금 준비 사다리
- 용돈 계약서를 디지털로 보관하고 손가락으로 서명, 갱신 이력 관리
- 부모님 모드: 칭찬 편지, 노력 용돈 메뉴판, 적금·예금 등록, 백업

## 구성
- `index.html`, `js/`: 화면 (프레임워크 없음)
- `api/`: Vercel 서버 함수 (상태 저장, 사진, AI 잔액 읽기)
- 저장소: Vercel에 연결한 Upstash Redis (`KV_REST_API_URL`, `KV_REST_API_TOKEN`)
- AI: `ANTHROPIC_API_KEY` 환경변수 (코드에 넣지 않음)

## 로컬 실행
```
npm install
npm run dev   # http://localhost:5173 (저장은 .devdata 폴더)
```
